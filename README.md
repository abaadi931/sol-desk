# sol-desk

Public, view-only dashboard for a **paper-trading** Solana desk (sol-desk v2).

- No real money, no wallet, no keys
- Anyone can watch; no one can edit
- Live page: https://abaadi931.github.io/sol-desk/

Prices on open positions refresh from DexScreener every few seconds while the page is open. Balance and trades update about once a minute (GitHub Pages may cache for a short time).
